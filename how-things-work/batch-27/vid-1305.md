## Fact check

- Many washing machine door interlocks use a PTC heater acting on a bimetal element (or wax actuator) to drive a locking pin; on power-off the heater must cool before release, typically 1-2 minutes. Some newer machines use solenoid locks that release faster.
- Control logic keeps the door locked while water is above the door level or the drum is turning.
