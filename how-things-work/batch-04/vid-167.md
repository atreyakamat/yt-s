## Fact check

- A typical home router combines a Wi-Fi access point, an Ethernet switch, a DHCP server (hands out local IP addresses) and a NAT router (shares one public address).
- 2.4 GHz travels further through walls; 5 GHz carries more data at shorter range.
- Many ISP-supplied boxes also include the modem.
- Main system-on-chip is a few centimetres or smaller: 'smaller than a postage stamp' is typical of router SoCs (the chip package, not the board).
