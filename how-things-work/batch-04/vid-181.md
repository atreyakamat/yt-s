## Fact check

- A lens focuses an image at a distance set by its focal length; the sensor must sit at that distance for a sharp image.
- For a given field of view, focal length scales with sensor size, so larger sensors and telephoto lenses need taller lens stacks.
- Phone camera modules use stacks of several molded plastic aspheric lens elements and a focus actuator above the image sensor; module height often exceeds phone body thickness, hence the bump.
