## Fact check

- Operating systems use write caching: data can sit in RAM and be written to the drive later.
- Removing a drive before cached writes are flushed can corrupt files or the file system.
- 'Eject' / 'Safely remove' flushes caches and unmounts the volume.
- Windows defaults removable drives to 'Quick removal' (less caching) but other systems and settings cache; hence 'not every computer'.
- Bars are illustrative, not measured.
