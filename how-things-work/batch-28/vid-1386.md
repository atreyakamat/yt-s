## Fact check

- Calculator keypads (and computer numeric keypads) place 7-8-9 on the top row; telephone keypads place 1-2-3 on top.
- Calculator layouts followed mechanical adding machines/cash registers, where higher digits were placed at the top.
- Bell Labs human-factors studies around 1960 tested keypad layouts for push-button phones and chose the 1-2-3 top row layout.
- Exact reasons for the adding machine layout are not fully documented, so the script says only that calculators followed them.
