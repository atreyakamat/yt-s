## Fact check

- Cordless stick vacuums typically use packs of cylindrical lithium-ion cells (e.g. 18650/21700, the format used in many laptop packs) wired in series to raise voltage.
- They use compact high-speed brushless motors; boost modes draw much more power and shorten runtime substantially versus eco modes.
- Some models run only while a trigger is held.
- Battery management systems monitor cell voltage and temperature for safety.
