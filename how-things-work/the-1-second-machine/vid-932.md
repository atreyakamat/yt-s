## Fact check

- Search engines crawl the web in advance and build an inverted index mapping words to documents and positions.
- Queries are answered from the index, which is sharded across many machines that work in parallel.
- Results are ranked using many signals (search engines describe 'hundreds' of ranking factors).
- Typical searches return in a fraction of a second.
