## Fact check

- Typical banknote counters run at around 1,000-1,500 notes per minute using friction rollers to feed notes singly.
- Infrared/optical sensors detect each note passing; thickness or transmission sensors detect doubles.
- Many counters include UV and magnetic (MG) counterfeit detection.
- 1,000 per minute ≈ 16.7 per second.
