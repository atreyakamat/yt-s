## Fact check

- Self-inking stamps hold the rubber die against an internal ink pad; pressing the frame rotates the die 180° via guide slots so it prints, and a spring returns it to the pad.
- Replaceable pads typically last thousands of impressions, depending on size and use. Gauge is illustrative.
