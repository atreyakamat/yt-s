## Fact check

- World Athletics rules use start information systems in the blocks; a reaction under 0.100 s after the gun is ruled a false start.
- The 0.1 s limit is based on research into the minimum time to hear and respond to a sound.
- Since 2010, a single false start disqualifies an athlete in most senior events.
- Elite sprint reaction times are typically around 0.12-0.18 s.
- Major meets place a speaker behind each athlete's blocks so all hear the start signal simultaneously; sound travels about 343 m/s, so distance would otherwise matter.
