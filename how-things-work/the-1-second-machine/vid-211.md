## Fact check

- Refresh rate is how many times per second a display updates; 60 Hz is about 16.7 ms per frame, 120 Hz about 8.3 ms.
- Displays show discrete still frames; apparent motion comes from rapid succession (persistence of vision / beta movement).
- Many phones with LTPO OLED panels use variable refresh rates and can drop as low as 1-10 Hz for static content to save power.
