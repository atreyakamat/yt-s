## Fact check

- Focal-plane shutters in interchangeable-lens cameras use two curtains (first and second) just in front of the sensor.
- At fast speeds, the second curtain starts before the first finishes, so a slit travels across the frame; each point is exposed for the set time (e.g., 1/4000 s, a common top speed; some reach 1/8000 s).
- 1/4000 s = 0.25 ms; a blink is roughly 100-400 ms (150 shown).
- Phones use electronic rolling shutters that read rows sequentially, which can distort fast-moving objects such as propellers.
