## Fact check

- Mouse buttons use microswitches that click shut when pressed.
- The operating system timestamps button events and treats two clicks within the double-click time as a double-click.
- Windows' default double-click time is 500 ms; it is adjustable in settings (the bars show example settings).
- Windows also requires the second click to fall within a small rectangle (a few pixels) of the first.
