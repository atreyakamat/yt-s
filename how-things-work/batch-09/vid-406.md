## Fact check

- Common dual-rumble gamepads use two eccentric rotating mass (ERM) motors, one with a larger weight (low-frequency rumble) and one with a smaller weight (high-frequency buzz).
- Games set each motor's speed independently to create effects.
- Some newer controllers use voice-coil / linear actuators ('HD' haptics) for finer effects.
