## Fact check

- EMV chip cards contain a secure microcontroller with memory and cryptographic keys.
- Contact chips are powered by the terminal through the contacts; ISO/IEC 7816 contacts include VCC (power), GND, CLK, RST and I/O.
- Each transaction includes a cryptogram generated with a card-held key, so replayed data fails.
- Magnetic stripes store static data that can be skimmed and cloned.
