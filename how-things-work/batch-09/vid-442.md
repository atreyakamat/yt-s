## Fact check

- A ratchet wrench uses a gear and a spring-loaded pawl: the pawl locks against the teeth in one direction and slides over them (clicking) in the other.
- The reversing switch changes which way the pawl engages.
- Minimum swing arc = 360 / number of teeth for a single pawl: 24 teeth = 15°, 36 = 10°, 72 = 5°.
