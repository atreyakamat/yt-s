## Fact check

- Manual call points were traditionally 'break glass' units; modern ones commonly use a resettable plastic element that deforms when pressed, releasing a switch.
- Operating the call point changes the circuit state, signalling the fire alarm control panel, which activates sounders and indicates the zone.
- Resettable call points are reset with a special key. Grid count is illustrative.
