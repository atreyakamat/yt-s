## Fact check

- Outline fonts (TrueType, OpenType, PostScript) store glyphs as Bézier curves (quadratic or cubic).
- Rasterisation scales outlines to the target size and fills pixels; anti-aliasing shades edge pixels.
- Fonts include kerning data adjusting spacing for pairs such as 'AV'. Bar values are illustrative.
- OpenType fonts can hold up to 65,535 glyphs; many contain thousands.
