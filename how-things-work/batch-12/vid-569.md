## Fact check

- Classic wired door chimes run on a low-voltage transformer; the push button closes the circuit.
- A solenoid (coil) pulls a steel plunger which strikes one tone bar ('ding'); on release, a spring drives it back to strike a second bar ('dong').
- Longer bars of the same section ring at a lower pitch. Timing 'about a second' depends on how long the button is held, presented loosely.
