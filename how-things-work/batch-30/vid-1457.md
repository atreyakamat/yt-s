## Fact check

- GIF was introduced by CompuServe in 1987; the 89a version (1989) added animation features such as frame delays and looping (via extensions).
- Each GIF frame uses a colour table of up to 256 colours; pixels store indexes into that palette.
- Images with more colours are approximated, often with dithering.
- GIF uses lossless LZW compression.
- GIF created 1987 (CompuServe); animation in GIF89a, 1989; up to 256 colours per frame palette: OK. Source: https://en.wikipedia.org/wiki/GIF
