## Fact check

- Methane combustion: CH4 + 2O2 -> CO2 + 2H2O, so burning gas produces water vapour.
- Condensing boilers cool flue gases below their dew point using return water, recovering latent heat of condensation; non-condensing boilers vent it.
- The condensate (slightly acidic) drains via a plastic condensate pipe; external sections can freeze in very cold weather and cause the boiler to lock out, a common winter fault in the UK.
