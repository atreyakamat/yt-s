## Fact check

- DRAM stores each bit as charge in a capacitor with one access transistor (1T1C cell).
- Charge leaks, so DRAM must be refreshed; the standard refresh interval is 64 ms (about 15 times a second).
- 16 GB = 128 gigabits, about 128 billion bit cells (ignoring error-correction extras).
- DRAM is volatile: data is lost shortly after power is removed, which is why unsaved work is lost.
- DRAM refresh window 64 ms (about 15 times a second): OK; DDR5 can use 32 ms so the title now says 'at least 15'. Source: https://arxiv.org/pdf/2209.10198
- 16 GB is about 128 billion bits (16 x 8 billion): OK arithmetic.
