## Fact check

- Airline bag tags carry a 10-digit license plate number as a barcode, plus the destination airport code and passenger name.
- Large airports' baggage handling systems contain many kilometres of conveyors.
- Automatic tag readers use arrays of laser scanners around the belt to read the barcode in any orientation.
- Hold baggage is screened, and suspect bags are diverted for further inspection.
- Sortation uses pushers, diverters or tilt trays; some airports and airlines use RFID tags.
