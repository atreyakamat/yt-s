## Fact check

- In a string (tin can) telephone, sound vibrates a diaphragm; the vibration travels along a taut string and moves the diaphragm at the other end. Source: https://en.wikipedia.org/wiki/String_telephone
- The string must be kept taut so vibration can travel along it. Source: https://en.wikipedia.org/wiki/String_telephone
