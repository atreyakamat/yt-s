## Fact check

- Electric current needs a complete circuit.
- Trams draw current from a single overhead wire and return it via the running rails.
- Trolleybuses have rubber tyres, so they need a second overhead wire for the return, collected by a second pole.
- Trolley poles are spring-loaded and use sliding shoes on the wires, allowing some lateral movement off the wire line.
- Trolleybuses need two wires and two poles to complete the circuit; trams use the track as return: OK. Source: https://en.wikipedia.org/wiki/Trolleybus
