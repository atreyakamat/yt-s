## Fact check

- Mesh Wi-Fi systems use multiple nodes broadcasting the same network name (SSID).
- Nodes relay traffic over wireless (or wired) backhaul to the node connected to the modem.
- Mesh systems use steering/roaming features (e.g. 802.11k/v/r) to move clients to better nodes.
- Single-radio repeaters receive and retransmit on the same channel, roughly halving throughput; tri-band mesh nodes use a dedicated backhaul radio.
