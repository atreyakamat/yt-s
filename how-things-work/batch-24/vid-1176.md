## Fact check

- Card magnetic stripes contain iron-oxide-based particles magnetised in patterns (flux reversals), like audio tape.
- Read heads are coils; a changing magnetic field induces voltage pulses (Faraday's law), decoded using F2F (two-frequency) encoding where timing between reversals encodes bits.
- Inconsistent swipe speed can cause read errors; strong magnets can demagnetise low-coercivity stripes.
- Static stripe data is easy to skim, one reason chip (EMV) cards replaced swiping. Grid is illustrative.
