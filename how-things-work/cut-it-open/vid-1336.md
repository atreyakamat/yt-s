## Fact check

- Display power is a major share of wearable and phone power use, especially at high brightness.
- OLED pixels showing black emit no light and use almost no power, so always-on faces use mostly black backgrounds.
- LTPO OLED panels can drop the refresh rate to 1 Hz in always-on mode.
- Many devices offload always-on rendering to a low-power display controller or sensor hub so the main processor can sleep.
