## Fact check

- Calculator digits use seven-segment displays; '2' uses 5 segments, '1' uses 2, '7' uses 3, '4' uses 4, '8' uses all 7.
- Twisted nematic LCDs place liquid crystal between crossed polarisers; with no voltage the twist rotates light so it passes and reflects off the back; voltage untwists the crystals and the segment goes dark.
- LCDs do not emit light and draw very little power.
