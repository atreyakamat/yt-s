## Fact check

- Dry erase inks contain pigment, an oily silicone-type release agent, and an alcohol solvent.
- The release agent keeps the pigment from bonding to the non-porous board surface, so it can be wiped off.
- Permanent markers use resins that bond to surfaces.
- Ink left a long time can leave 'ghosting' that is harder to remove.
