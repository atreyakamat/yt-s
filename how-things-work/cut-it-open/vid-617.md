## Fact check

- Motherboards host the CPU socket, memory slots and expansion/storage connectors.
- Motherboards are multilayer PCBs, commonly 6-12 copper layers separated by fibreglass (FR-4).
- Memory buses send many bits in parallel; serpentine 'length-matching' traces equalise path lengths so signals arrive together.
- Timing skews involved are on the order of picoseconds to nanoseconds.
