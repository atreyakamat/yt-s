## Fact check

- Primary radar shows reflections without identity or altitude.
- Secondary surveillance radar interrogates transponders, which reply.
- Mode A replies give a four-digit squawk code assigned by ATC; Mode C/S add pressure altitude (Mode S and ADS-B add more data).
- Squawk 7700 is the general emergency code.
