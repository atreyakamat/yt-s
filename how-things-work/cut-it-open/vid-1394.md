## Fact check

- Door entry systems in flats use a call panel, handsets in each flat and a release button.
- An electric strike replaces the frame's strike plate; its hinged keeper is held by a mechanism that a solenoid releases when powered (fail-secure type), so the latch can push it aside.
- AC-powered strikes vibrate audibly when energised: the familiar door buzz.
