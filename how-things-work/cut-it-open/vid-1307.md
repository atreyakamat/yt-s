## Fact check

- TCP and UDP use 16-bit port numbers: 0-65,535, i.e. 65,536 ports per protocol per address.
- HTTPS uses port 443; SMTP uses port 25.
- Firewalls filter connections by rules; stateful firewalls allow return traffic for connections the device initiated and block unsolicited inbound connections by default.
- Automated scanners continuously probe internet addresses for open ports.
- Home routers' NAT plus firewall block unsolicited inbound traffic for the network.
