## Fact check

- Modern cruise control is a closed-loop controller: the engine computer compares measured speed (from wheel/vehicle speed sensors) with the set speed and adjusts the electronic throttle continuously, many times a second.
- Pressing the brake (or clutch on manual cars) cancels cruise control.
- Adaptive cruise control uses forward radar (sometimes with a camera) to keep a gap to the vehicle ahead.
