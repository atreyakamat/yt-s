## Fact check

- Many robot vacuums use a rotating lidar unit in a turret on top that measures distance by timing reflected laser light; others use cameras, and basic models navigate by bumping.
- Lidar units take thousands of distance samples per second, which mapping software (SLAM) turns into a floor plan.
- Wheel encoders and gyroscopes track distance and heading (odometry).
- Downward-facing infrared cliff sensors detect drops such as stairs; a sprung bumper detects collisions.
- Robots return to the dock using the map and/or an infrared homing signal from the dock.
