## Fact check

- Authenticator apps generally use TOTP (RFC 6238): a shared secret, provisioned via QR code, combined with the current time in 30-second steps through an HMAC to produce a 6-digit code.
- Both sides compute the code independently, so the app needs no network connection.
- Servers usually accept the current and maybe adjacent time step, so a code is useless within about a minute.
- Six digits give 1,000,000 possible codes.
