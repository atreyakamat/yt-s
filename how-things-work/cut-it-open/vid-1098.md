## Fact check

- The malfunction indicator lamp is controlled by the engine control unit's on-board diagnostics, which monitors sensors and stores diagnostic trouble codes.
- OBD-II has been required on US cars since 1996 and EOBD on EU petrol cars since 2001; the standard 16-pin port is usually under the dashboard.
- Codes start with a system letter (P = powertrain); a second digit 0 marks a generic code; P0420 means catalyst efficiency below threshold.
- A flashing MIL indicates a severe misfire that can damage the catalytic converter; a loose fuel cap can set an evaporative system leak code.
