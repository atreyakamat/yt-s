## Fact check

- OLED displays use organic (carbon-based) semiconductor layers between electrodes that emit light when current flows; each subpixel emits its own light.
- A thin-film transistor backplane controls current to each subpixel, setting brightness.
- LCDs use a backlight with liquid crystal and colour filters; some light leaks through in black areas. In OLED, black pixels are unlit, giving true black.
