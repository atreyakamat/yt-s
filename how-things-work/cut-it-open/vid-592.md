## Fact check

- Click-type torque wrenches have a coil spring in the handle that preloads a pivoting block (or cam) against the head; when applied torque exceeds the preload the block breaks over, producing a click and a felt release.
- Turning the handle adjusts spring compression and so the set torque.
- Tightening a bolt stretches it elastically; that stretch provides the clamping (preload) force, which torque specs aim to control.
- Typical values: car wheel nuts about 80-140 Nm (around 100 is common); bicycle stem bolts about 4-6 Nm. Always use the maker's figure.
