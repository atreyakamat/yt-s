## Fact check

- Properly designed systems store password hashes (ideally with a slow algorithm like bcrypt, scrypt or Argon2), not the passwords.
- Cryptographic hashes are deterministic and practically one-way.
- Login works by hashing the entered password (with the stored salt) and comparing.
- Avalanche effect: a one-character change flips about half the output bits, hence the 50% bar.
- A salt is random data added per user so identical passwords produce different hashes.
