## Fact check

- Separate pastes → striped toothpaste uses a main paste plus a coloured stripe paste.
- Insert in the neck → the classic design (patented by Leonard Marraffino, filed 1955) has the stripe material in the neck and an insert tube; squeezing pushes stripe paste through holes onto the main paste as it exits.
- Thick, viscous pastes flow in a smooth (laminar) way, so they don't blend in the tube.
