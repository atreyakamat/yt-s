## Fact check

- Telescopic luggage handles use nested aluminium (or steel) tubes.
- A button in the grip moves an internal rod or cable that retracts spring-loaded locking pins; released pins engage holes at set heights. Exact linkages vary by maker, so the script stays general.
- Bernard Sadow patented a wheeled suitcase in 1970; Northwest Airlines pilot Robert Plath created the upright 'rollaboard' with a telescoping handle in 1987.
