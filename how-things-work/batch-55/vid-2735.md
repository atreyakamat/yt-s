## Fact check

- A sandbox isolates running programs; mobile operating systems sandbox each app with its own storage and permissions. Source: https://en.wikipedia.org/wiki/Sandbox_(computer_security)
- Apps request permissions from the OS, which asks the user. Source: https://en.wikipedia.org/wiki/Sandbox_(computer_security)
- Software updates patch security flaws. Source: https://en.wikipedia.org/wiki/Patch_(computing)
