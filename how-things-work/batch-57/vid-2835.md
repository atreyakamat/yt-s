## Voiceover (read-through)

1. Kimchi bubbles because it's alive.
2. Lactic bacteria ferment the cabbage's sugars.
3. That makes acid, which preserves the food.
4. It also makes carbon dioxide gas.
5. So jars need space and the occasional release.
6. Cold slows the process, so the fridge keeps it stable.
