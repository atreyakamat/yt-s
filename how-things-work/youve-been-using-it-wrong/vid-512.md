## Fact check

- Tactile ridges on F and J mark the home-row positions for the index fingers in touch typing.
- Touch typing assigns each finger a set of keys and lets typists keep eyes on the screen; touch typists are generally faster than hunt-and-peck typists.
- Numeric keypads have a bump on the 5 key for the middle finger.
- The gauge value is illustrative.
