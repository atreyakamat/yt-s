## Fact check

- Guitar tuners are worm-gear machines that wind the string around a post.
- Gear backlash and string friction at the nut can leave slack when you tune down to pitch, which can then settle and drift flat.
- Tuning up to the note (and dropping below first if you overshoot) is standard guitar-teaching advice for tuning stability.
