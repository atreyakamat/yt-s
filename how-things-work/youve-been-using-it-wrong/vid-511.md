## Fact check

- Both major phone operating systems suspend background apps, keeping them in memory with little or no CPU use, and reclaim memory automatically.
- Relaunching a terminated app ('cold start') costs more CPU work and energy than resuming a suspended one.
- Apple and Google support guidance says force-quitting is only needed when an app is unresponsive, and does not improve battery life.
