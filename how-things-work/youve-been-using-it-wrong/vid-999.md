## Fact check

- Reel drag systems use stacked metal and friction washers pressed against the spool; the knob sets the pressure.
- When line tension exceeds the drag setting, the spool slips and releases line, protecting the line from breaking.
- A widely used guideline is to set drag at roughly 25-33% of the line's rated breaking strength; for 12 lb line that's about 3-4 lb.
- Anglers commonly back off the drag for storage so the washers don't stay compressed.
