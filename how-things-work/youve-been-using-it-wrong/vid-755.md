## Fact check

- The US MUTCD calls for reference-location (milepost-based) exit numbering, and most states use it; mileposts start at zero at the south or west state line.
- So the difference between two exit numbers is roughly the miles between them.
- Sequential numbering forced suffixes like 12A when exits were added; several northeastern states have since converted to mileage-based numbers, while a few still use sequential ones.
