## Fact check

- Peeling upward bends the note across the adhesive strip, causing it to curl; peeling sideways keeps the strip flat (a widely shared tip, also recommended by the manufacturer).
- Sticky note adhesive is low-tack microspheres, so a curled note loses contact and falls more easily.
