## Fact check

- Swivel lever stored flat → standard lever-style nail clippers store the lever facing back over the jaws and rotate 180° to use.
- Compound lever → the lever presses a pin that closes the jaws, which are themselves a lever; this multiplies the force.
- File underneath → many clippers have a ridged file on the lever's underside ('many', not all).
