## Fact check

- Tilt-and-turn windows: handle down = locked; horizontal (90 degrees) = turn (side-hung inward opening); up (180 degrees) = tilt (bottom-hinged, top opens inward).
- Tilt mode gives secure ventilation with a limited opening.
- Manufacturers warn against turning the handle while the sash is open, as this can mis-engage the hinges (the sash can hang from one corner).
