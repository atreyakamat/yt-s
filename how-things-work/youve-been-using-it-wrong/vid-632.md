## Fact check

- Browsers' private modes don't save browsing history, cookies, site data or form entries after the private session closes.
- Browsers state that private mode doesn't hide activity from websites, employers/schools or internet service providers.
- Logging into accounts identifies you to that site.
- Downloaded files and bookmarks created in private mode are kept.
