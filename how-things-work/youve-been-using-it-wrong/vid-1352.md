## Fact check

- Holding a router's recessed reset button (often around 10 seconds) restores factory defaults.
- A factory reset reverts the network name and password to the defaults printed on the label and erases custom configuration, so devices must reconnect.
- The button is recessed to prevent accidental presses.
- Power cycling restarts the router without erasing settings.
