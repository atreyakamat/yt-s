## Fact check

- In end-to-end encryption only the communicating users hold the keys to read messages; servers cannot. Source: https://en.wikipedia.org/wiki/End-to-end_encryption
- Key agreement lets two parties derive a shared secret over a public channel (Diffie-Hellman). Source: https://en.wikipedia.org/wiki/Diffie%E2%80%93Hellman_key_exchange
- Apps can display a verification code to compare. Source: https://en.wikipedia.org/wiki/End-to-end_encryption
