## Fact check

- Smart locks use a motor to turn the lock's bolt or thumb-turn after receiving an authorised command from a phone or key. Source: https://en.wikipedia.org/wiki/Smart_lock
- Good implementations encrypt the wireless message; many include a physical key backup and run on batteries: model-dependent, so the script says 'good ones' and 'many'. Source: https://en.wikipedia.org/wiki/Smart_lock
