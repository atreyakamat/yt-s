## Fact check

- Permanent marker ink uses a resin that resists water; alcohol-type solvents soften it.
- Dry erase markers contain alcohol solvents and release agents; drawing over permanent marker on a non-porous board loosens it so both wipe off (a widely documented tip, also given by marker makers).
- Abrasive cleaners scratch whiteboard surfaces, which then hold ink.
