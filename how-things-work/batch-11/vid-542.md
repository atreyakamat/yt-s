## Fact check

- The common save icon depicts a 3.5-inch floppy disk (shutter, label, square case).
- Floppies were the main removable storage in the 1980s-1990s and faded in the 2000s.
- The icon persists because users recognise it; the same applies to the envelope (mail) and handset (call) icons.
- A skeuomorph is a design that keeps features of an older object; the term is widely used for such icons.
