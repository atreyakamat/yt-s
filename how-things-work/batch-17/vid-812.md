## Fact check

- Email clients submit messages to the sender's outgoing (SMTP) server.
- The sending server looks up the recipient domain's MX record in DNS to find the receiving mail server.
- Attachments are encoded as text (Base64), which increases size by about 33%: 3 MB becomes about 4 MB.
- Receiving servers run spam checks before delivering to the mailbox; clients get push notifications. Delivery is typically seconds.
