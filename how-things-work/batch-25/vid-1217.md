## Fact check

- Digital computers store and process data as bits, implemented with transistor switches.
- 8 bits = 1 byte = 2^8 = 256 values.
- In ASCII/Unicode, 'A' = 65 = 01000001 in binary.
- Images are stored as numeric colour values per pixel (often compressed).
- Two-level signals are robust to noise, a key reason computers use binary.
- A byte has 256 patterns; ASCII capital A = 01000001 = 65: arithmetic and standard ASCII. Source: https://en.wikipedia.org/wiki/ASCII
