## Fact check

- The Resin Identification Code (numbers 1-7 in a triangle) was introduced in 1988 by the Society of the Plastics Industry to identify resin type for sorting; it does not indicate recyclability.
- Code 1 (PET, drink bottles) and code 2 (HDPE, milk jugs) are the most widely accepted; code 6 (polystyrene) and code 7 (other/mixed) are often not accepted kerbside. Acceptance varies by area.
- The ASTM D7611 standard now specifies a solid equilateral triangle instead of chasing arrows to reduce confusion.
- SPI resin codes introduced in 1988 to help sort plastics, not to promise recyclability; 1 = PET, 2 = HDPE: OK. Source: https://en.wikipedia.org/wiki/Resin_identification_code
