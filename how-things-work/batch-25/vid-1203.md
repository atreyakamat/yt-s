## Fact check

- Many early cars were open-bodied; motorists relied on heavy clothing, blankets and foot warmers (containers of hot coals or heated bricks).
- Some early heaters used exhaust heat, risking carbon monoxide leaks.
- Hot-water heaters using engine coolant and a small heater core with a fan spread over the following decades (exact 1920s/1930s dates not confirmed, so the script says "later"); modern car heaters work the same way (heater matrix with circulating engine coolant).
