## Fact check

- MIT's Compatible Time-Sharing System (CTSS), led by Fernando Corbató, introduced passwords in the early 1960s (around 1961) so users sharing the computer could have private files and time quotas.
- Early batch computers ran one job at a time without user logins.
- In 1962 Allan Scherr, wanting more than his allotted computing time, requested a printout of the password file and later shared it.
- Modern systems should store salted hashes rather than plaintext passwords.
- The gauge value is illustrative.
