## Fact check

- DNS translates domain names into IP addresses.
- Devices usually query a recursive resolver (often the ISP's, or a public one).
- Resolution walks from root servers to TLD servers (e.g. .com) to the domain's authoritative servers.
- There are 13 named root server identities (A-M), served by over a thousand instances worldwide using anycast.
- Answers are cached for their time-to-live (TTL).
- DNS outages have made working sites unreachable.
