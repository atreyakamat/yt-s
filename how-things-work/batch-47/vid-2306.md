## Fact check

- Chip uses the ISO/IEC 14443 contactless interface and ICAO Doc 9303; it stores a facial image and details. Source: https://en.wikipedia.org/wiki/Biometric_passport
- Reader derives the access key from the machine readable zone (document number, date of birth, expiry date). Source: https://en.wikipedia.org/wiki/Biometric_passport
- Chip holds a Document Security Object with a digital signature in a country PKI chain. Source: https://en.wikipedia.org/wiki/Biometric_passport
- Some countries, including the US, add a thin metal mesh in the cover to shield the chip (optional). Source: https://en.wikipedia.org/wiki/Biometric_passport
- A passive chip is powered by the reader's radio field, like any contactless card. Source: https://en.wikipedia.org/wiki/Biometric_passport
