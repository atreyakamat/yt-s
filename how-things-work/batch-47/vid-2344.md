## Fact check

- A deadbolt has no spring-loaded angled latch; it is moved only by key or thumb-turn rotating a cam. Source: https://en.wikipedia.org/wiki/Deadbolt
- Longer screws in the strike plate reach the frame stud: common installation guidance, no figures used.
- Wikipedia: a deadbolt can only be opened by key or handle, whereas a spring bolt can be pushed back by force on the bolt itself. 'Square-ended' is a general description of the bolt. Source: https://en.wikipedia.org/wiki/Deadbolt
