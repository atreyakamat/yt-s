## Fact check

- A delta update sends only the differences between versions instead of the whole file. Source: https://en.wikipedia.org/wiki/Delta_update
- Mobile platforms verify the digital signature of apps before installing or updating them. Source: https://en.wikipedia.org/wiki/Code_signing
- App data is kept in separate storage from app code on modern mobile systems (sandboxing). Source: https://en.wikipedia.org/wiki/Sandbox_(computer_security)
