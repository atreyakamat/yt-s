## Fact check

- The clipboard is a temporary storage area in memory provided by the operating system for copy and paste between applications. Source: https://en.wikipedia.org/wiki/Clipboard_(computing)
- Clipboard data can be stored in multiple formats at once. Source: https://en.wikipedia.org/wiki/Clipboard_(computing)
- Modern mobile systems notify users when apps read the clipboard. Source: https://en.wikipedia.org/wiki/Clipboard_(computing)
