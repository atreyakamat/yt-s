## Fact check

- Transformer hum comes mainly from magnetostriction: the iron core changes dimension slightly as it is magnetised, which happens twice per AC cycle regardless of direction.
- So the fundamental hum is at twice mains frequency: 100 Hz on 50 Hz grids (UK), 120 Hz on 60 Hz grids (North America).
- High-voltage lines crackle from corona discharge, which can glow faintly and is typically louder in wet weather.
- Transformer hum is twice the mains frequency (100 Hz at 50 Hz, 120 Hz at 60 Hz), partly magnetostriction: OK. Source: https://en.wikipedia.org/wiki/Mains_hum
