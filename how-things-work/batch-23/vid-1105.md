## Fact check

- Jet nebulisers use compressed air forced through a narrow orifice; the high-velocity jet lowers pressure (Bernoulli/Venturi effect), drawing liquid up a feed tube.
- The liquid is sheared into droplets; baffles catch large droplets, which return to the reservoir, so only fine aerosol leaves.
- Mesh nebulisers use a vibrating mesh with thousands of micro-holes. Bars are illustrative. Educational only, not medical advice.
