## Fact check

- Pages load many resources (HTML, CSS, JS, images).
- Browsers store cacheable responses in an HTTP cache on disk/memory.
- Servers set cache lifetimes via headers like Cache-Control; browsers revalidate stale entries.
- Clearing the cache forces fresh downloads, fixing issues from stale files. Load times in the bars are illustrative.
