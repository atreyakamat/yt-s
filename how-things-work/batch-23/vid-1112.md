## Fact check

- The Insert key toggles between insert mode and overtype (overwrite) mode in many text editors and word processors.
- In overtype mode each typed character replaces the character after the cursor.
- Overtype suits fixed-width fields/data entry; some apps (e.g. modern word processors) disable it by default.
- On many laptops Insert is a secondary function accessed with Fn.
- The gauge is illustrative.
