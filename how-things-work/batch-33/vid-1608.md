## Fact check (verify before posting)

Task-switching costs documented (Rubinstein, Meyer & Evans 2001); 'time lost' estimates like 40% are popular but weakly sourced—avoid numbers. Dual-task interference is robust for tasks needing the same cognitive resources.

## Voiceover (read-through)

2. Switching between tasks costs time.
3. Each switch takes a moment to refocus.
4. Errors rise when attention is split.
5. Some tasks are automatic, like walking and talking.
6. For real work, do one thing at a time.
