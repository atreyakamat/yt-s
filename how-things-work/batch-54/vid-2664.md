## Fact check

- A U2F security key answers a challenge using public-key cryptography; the private key exists only in the hardware. Source: https://en.wikipedia.org/wiki/Universal_2nd_Factor
- The signature encodes the originating website, so an intercepted response cannot be reused on a different phishing site. Source: https://en.wikipedia.org/wiki/Universal_2nd_Factor
