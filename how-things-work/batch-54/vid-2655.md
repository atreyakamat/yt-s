## Fact check

- Optical character recognition converts images of text to machine-readable text. Source: https://en.wikipedia.org/wiki/Optical_character_recognition
- Machine translation converts text between languages, increasingly using context via neural networks. Source: https://en.wikipedia.org/wiki/Machine_translation
- Inpainting fills removed image regions from surroundings. Source: https://en.wikipedia.org/wiki/Inpainting
