## Fact check

- A yo-yo string is a loop around the axle, not tied to it; this 'slip string' design lets the yo-yo spin at the end of the string ('sleep').
- Falling converts height (potential energy) into spin and motion.
- Many modern yo-yos use a ball bearing axle to cut friction and give long sleeps.
- A tug briefly lets the slack string catch on the axle or response pads, so it winds up and climbs.
- Response pads control grip; 'unresponsive' trick yo-yos don't return on a tug and need a bind trick.
