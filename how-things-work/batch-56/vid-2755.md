## Fact check

- Wi-Fi calling (voice over Wi-Fi) routes calls over a Wi-Fi network and the internet to the carrier's core network via a secure tunnel. Source: https://en.wikipedia.org/wiki/Voice_over_WLAN
- Usage and charges for roaming vary by carrier (script says check carrier). Source: https://en.wikipedia.org/wiki/Voice_over_WLAN
