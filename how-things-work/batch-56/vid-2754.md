## Fact check

- Multipoint locks use a handle-operated bar (an espagnolette-style mechanism) that engages hooks or bolts into the frame at several points. Source: https://en.wikipedia.org/wiki/Espagnolette
- If the handle is not lifted, only the latch holds the door: how these doors are designed to be operated. Source: https://en.wikipedia.org/wiki/Espagnolette
