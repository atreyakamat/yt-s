## Fact check

- A standard room thermostat switches the heating on below the set point and off above it.
- With an on/off control, the boiler runs at its normal output whenever it's called, so a higher set point doesn't heat faster; it only raises the point where it stops. Widely given energy advice (e.g. UK energy-saving guidance).
- Kept to basic on/off thermostats; the script doesn't claim anything about modulating controls.
- Setting a thermostat higher does not heat the room faster: widely stated, not independently sourced this pass.
