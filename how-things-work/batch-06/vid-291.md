## Fact check

- Optically variable ink contains multilayer thin-film flakes (e.g. absorber/dielectric/reflector) that produce colour by interference.
- Changing the viewing angle changes the optical path length, shifting which wavelengths interfere constructively.
- It is used on many banknotes, e.g. the numeral on recent US $10-$100 notes (copper to green).
- Soap bubbles and oil films show colour through the same thin-film interference.
- Copiers and scanners capture a single angle, so they cannot reproduce the shift.
