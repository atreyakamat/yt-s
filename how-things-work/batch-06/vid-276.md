## Fact check

- Basic four-function calculators use immediate execution: each operation is applied as the next operator is pressed, so 2+3×4 gives 20.
- Scientific calculators apply operator precedence (multiplication before addition), giving 14, the correct answer under standard order of operations.
- Typing 3×4+2 on a basic calculator gives 14.
- 2 + 3 x 4 = 14 by the standard order of operations; basic calculators that evaluate as you type give 20: arithmetic and definition, OK.
