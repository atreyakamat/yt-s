## Fact check

- Roman sentries let pass only those who knew the watchword, which was written on a wooden tablet collected each evening from the tribune's tent and passed unit to unit before witnesses; tablets were returned before dark so the tribune knew it had reached every unit, and a missing tablet showed where the chain failed. Polybius describes the Republican-era army (2nd century BCE); the tablet was collected near sunset and returned before nightfall. Source: http://www.perseus.tufts.edu/hopper/text?doc=Perseus%3Atext%3A1999.01.0234%3Abook%3D6%3Achapter%3D34 and https://en.wikipedia.org/wiki/Password
