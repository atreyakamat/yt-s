## Fact check

- The Open Graph protocol, created by Facebook in 2010, lets pages specify title, description and image via meta tags used for link previews. Source: https://en.wikipedia.org/wiki/Open_Graph_protocol
- Messaging and social apps fetch the page and read those tags. Source: https://en.wikipedia.org/wiki/Link_preview
