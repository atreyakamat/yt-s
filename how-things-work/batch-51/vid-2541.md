## Fact check

- Bob material: stone, wood or lead, other metals possible (brass removed as unsupported). A plumb bob is a weight on a string that gives a vertical reference line using gravity; used since at least ancient Egypt, where a plumb line hung from an E-shaped tool. Source: https://en.wikipedia.org/wiki/Plumb_bob
- Surveyors use plumb bobs to set up instruments over survey markers. Source: https://en.wikipedia.org/wiki/Plumb_bob
- A-frame levels with a plumb line were used in Europe until the mid-19th century. Source: https://en.wikipedia.org/wiki/Plumb_bob
