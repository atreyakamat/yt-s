## Fact check

- Modern protocols like QUIC support connection migration so a session survives an IP address change. Source: https://en.wikipedia.org/wiki/QUIC
- Moving between Wi-Fi and cellular changes the device's IP address. Source: https://en.wikipedia.org/wiki/IP_address
- Streaming apps buffer ahead to cover short gaps. Source: https://en.wikipedia.org/wiki/Streaming_media
- Gauge value is illustrative.
