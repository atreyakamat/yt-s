## Fact check

- Unicode assigns code points: 'A' is 65 (U+0041), '€' is 8364 (U+20AC), 😀 is 128512 (U+1F600).
- Unicode includes over 3,000 emoji (around 3,700+ including sequences).
- Emoji are transmitted as code points; each platform renders with its own emoji font, so designs differ.
- Family and many other emoji are ZWJ sequences: several emoji joined by the zero-width joiner.
- Skin tones are Fitzpatrick modifier code points following a person emoji.
