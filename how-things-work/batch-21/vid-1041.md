## Fact check

- Cheques use MICR (magnetic ink character recognition): the code line is printed with ink containing iron oxide, in a special font (E-13B in the US/UK, CMC-7 elsewhere).
- Readers magnetise the characters, and a read head produces a distinctive waveform for each character shape.
- Non-magnetic overprinting such as stamps or signatures does not interfere.
- MICR was developed in the 1950s and adopted by US banks by the late 1950s/early 1960s.
