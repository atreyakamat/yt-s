# Cutaway render engine

Remotion project that turns `how-things-work/**/vid-xx.md` into 1080x1920 MP4s. See the [root README](../README.md) for setup and commands.

- `npm run dev`: sync scripts and open Remotion Studio
- `npm run build:reel -- vid-01`: render one reel to `../out/`
- `npm run lint`: validate every script, then eslint + tsc
